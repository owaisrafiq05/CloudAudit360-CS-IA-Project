2. Methodology

Compliance scoring: Per control, FAIL if any mapped check fails (unless covered by an approved active exception); PASS if all mapped checks pass; NOT_ASSESSED if no mapped check ran. Framework score = PASS / (PASS + FAIL + EXCEPTION) × 100. Coverage excludes NOT_ASSESSED from the score denominator.

Risk scoring (5×5): Likelihood from asset exposure (public=5, internal=3, private=2) with +1 for high/critical severity (capped at 5). Impact = round((severity_value + criticality_value) / 2). Inherent score = Likelihood × Impact. Bands: 1–4 Low, 5–9 Medium, 10–16 High, 17–25 Critical.
